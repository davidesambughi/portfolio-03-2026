# Session Handoff

1. Read CLAUDE.md for project context
2. Summarize what was completed in this session
3. List what is still open or unresolved
4. Note any bugs discovered but not fixed
5. Write the exact next step to start with in the next session
6. Save everything to docs/handoff.md

## Rules
- Be specific. No vague summaries.
- The next step must be actionable — one concrete task, not a category.
- Save the file before telling me it's done.
