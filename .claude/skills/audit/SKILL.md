# Codebase Audit

1. Read CLAUDE.md for project context
2. Scan all source files, cross-reference with any existing audit docs in /docs
3. Categorize issues: critical bugs, code quality, missing features
4. Save findings to docs/audit-YYYY-MM-DD.md
5. Present a prioritized table of top 10 items

## Rules
- Do NOT fix anything. Only analyze and report.
- Work through files one at a time. Do not summarize everything at once.
- After saving the findings file, confirm the path before moving on.
